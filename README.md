# Кофе In — сайт-каталог с заказом в Telegram / MAX

Статический сайт без сервера: открыть `index.html` или выложить на GitHub Pages.

## Что править
Всё в **`config.js`**:
- `telegram` — номер (`79186956063`) или username (`kofe_in`), куда приходит заявка;
- `max` — ссылка на ваш профиль/чат в MAX;
- `items` — позиции каталога: название, описание, объёмы и цены, `tag: "Хит"`, необязательное фото `img`.

## Как уходит заявка
1. Гость собирает корзину, заполняет имя/телефон/время (самовывоз или доставка).
2. **Telegram** — открывается чат с номером кофейни, текст заказа уже подставлен, гость жмёт «Отправить».
3. **MAX** — текст копируется в буфер, открывается ваш чат в MAX, гость вставляет и отправляет.

> Чтобы ссылка по номеру работала, в Telegram у владельца номера должно быть: Настройки → Конфиденциальность → Номер телефона → «Кто может найти меня по номеру» = **Все**. Надёжнее указать username.

## Публикация на GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / `root`.
